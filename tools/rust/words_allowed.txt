# Places where a format's or a game program's real name is the fact. One entry per line:
#   path-glob | pattern (a regular expression) | reason
# A hit is allowed when its file matches the glob and its text matches the pattern. An entry that
# matches nothing fails the check, so the list cannot outlive its reasons.
