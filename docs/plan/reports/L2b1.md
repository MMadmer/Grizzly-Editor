# Report L2b1 - the level's left side: Place, Paint, Zones, and the World Outliner

## 1. Built

**The left panel (`crates/gz-ui-level/src/tools.rs`)** - no tile grid, no edit target, no per-tool picker. The
panel left of the viewport shows what the scene's mode works with, and its tab names it (`tools::tab_label`):
**Place** in Select and Place mode, **Paint** in Paint mode (a segmented AI Map | Foliage | Decals that sets
`SceneMode`), **Zones** in Zones mode. Panel id `place`, window `Place###LeftBar`.

**The Place panel (`place.rs`, new)** - one search, one virtualized list of kit `Section`s: Recent (the last 12,
layout list `place.recent`), Objects (the library's tree, each row with the object's `.thm` picture, read and
decoded on the IO pool, uploaded 4 a frame, 256 kept), Lights (Light, Glow), Spawn Points (Player Start,
Environment Modifier, Respawn Point, then the game's sections by their in-game names from `game.lookup
type=item_section`, grouped by their `$spawn` path, the section muted at the row's end), Shapes and Volumes (Sphere,
Box, AI Map Bounds, Fog Volume, Sound Environment), Sounds, Particles, Way Paths, Groups. The rows are a pure
function (`place::rows`) run as a `Query` keyed by (search, open sections, folder epoch, Recent) over the lists'
identities - no rebuild per keystroke on the UI thread (audit D1). A row drags the viewport's own payload
(`gz_ui_viewport::place::Placeable::payload`) and a click arms it (`place::arm`); the armed row is highlighted with a
"Placing <name> · Esc stops" line and a cross; a second click stops. Tooltips show the 128 px picture.

**Paint panels (`tools_bulk.rs`, rewritten)** - AI Map: node and selected counts (a `Query`, not a 625 k-node walk per
frame), where it is generated (inside the AI Map Bounds volume, or "Over the whole level" with [Place Bounds
Volume]), Can Climb / Can Drop, [Generate] (Primary), Clear... (GhostDanger + confirm); More: the brush, links,
side pad, selection tools, Ignored Materials (+/cross), drawing. Foliage: the meshes (+ adds through the chooser, a
kit drop `Zone` takes Place rows and Content Browser `.object`s, a cross removes after a question), a click picks
the brush's mesh (`gz_ui_viewport::set_brush`), the mesh's Density / Smallest / Largest / Sways in the Wind, Brush
Size and Strength, [Fill the Ground], Clear...; More: Colour Picture + Import Again, Colour Indices..., Objects per
Square, Draw Foliage. Decals: Texture, Width, Height, Turn, Delete Selected...; More: Shader, Alignment, Draw,
selection.

**Zones panel (`tools_objects.rs`, rewritten)** - first line "The build makes the cells and their portals by
itself ...", [New Cell From Selection] (Primary), [Compute Portals], [Validate], Cells and Portals lists with an eye
per row (a click selects), Remove Selected...; More: what a mesh click does, Pick by a Dragged Box, Take In What Is
Inside, Turn Portals Round, Remove the Default Cell..., the Level Bound (edit, Fit to the Level).

**Colour Indices dialog (`detail_objects.rs`)** - `Colour Indices###dlg.colour_indices` (L): a card per colour,
Add Colour, Clear All..., Import... / Export... of the `.dti`; the meshes are the Foliage panel's list.

**World Outliner (`outliner.rs`, `outliner_model.rs`)** - kinds ordered by their names (`classes::listed`), an eye
and a lock per kind and per object (`local_lock_toggle`: shown when locked or hovered), leaf names cut in the
middle with the whole name in the tooltip, By Hierarchy lists a way path's points (a point row selects the point
through `scene.way select_points`), type filter as kit `Check`s, search (Ctrl+F through Find in World Outliner).
**The scroll bug**: a selection made elsewhere is kept as a target until a listing *computed for the scene's
current revision with the revealing folds* places it (`scroll_decision`: Wait / Scroll / Drop); while a new key is
computed the last listing stays on screen (no "Listing..." flash). The row menu acts on the selection (a right click
selects the row first) and carries what the deleted tool forms did: Group, Ungroup, Save Group As..., Center the
Pivot, Pivot to an Object..., Reload From Its Asset, way links, Join / Split shapes, fog groups, give a shape to a
spawn / detach, Reset Surfaces, Select All Made From the Same, Select All <Kind>, Hide/Show, Lock/Unlock, Rename,
Delete... (naming every object).

**Commands (`view_cmd.rs`, new)**: `level.view` (effect `view`) answers mode, panel, the Place panel (search,
categories, rows with `payload`, armed), Paint and Zones state, the Outliner (filter, kinds, rows, scroll_y,
scroll_pending), the dialog; sets `place_search`, `place` (+ `ref`/`section`/`box`/`usage`, `none`), `category` +
`open` (+ `folder`), `outliner_search`, `selected_only`, `visibility`, `sort`, `layout`, `kinds`, `unfold`, `fold`,
`colour_indices`. Rows are computed fresh (the panel's own `Query::fresh`) before it answers.

**Shared helpers, one copy (`local.rs`)** - `run`, `confirm`, `removal`, `plural`, `args`, `local_danger`,
`local_eye_toggle`, `local_lock_toggle`; `local_tree_list` (the chooser's) now computes its rows through a `Query`
(audit D1). `local_tool_tile` and the twice-copied `run/danger/confirm/plural/switch_row` are gone.

**`classes.rs`** (icon, title, plural, the listing order), **`layout.rs`** (Tools -> Place, words on their own terms;
Problems min width 280 so the Compact right column stays 300), **`dock.rs`** (a comment).

## 2. Decisions

- Glows sit under Lights and Fog under Shapes and Volumes: single-row categories were clutter.
- The AI Map Bounds row is placed at once on the ground in front of the camera (`scene.place ... usage=ai_map_bounds
  on_surface=true`) and selected: the viewport's `Placeable` has no usage, so it cannot be armed or dragged.
- Random Append (Randomize Added Objects, Random Settings) has no surface any more (X-Ray's, audit B2); the scene's
  `random_placement` stays a Level Settings / `scene.set` value. Add Several, Select % of Same, Make Thumbnail, the
  Light tool's Viewport Lighting (B12, L2a), Attach on Click / shape attach by click (the menu's Give the Shape /
  Join Shapes replace them) and the dead Slow Calculate Mode switch are gone.
- Selection actions moved to the Outliner's row menu (UE's outliner context menu) instead of a form per kind.
- AI map "Add Nodes" is gone as a switch: in Paint > AI Map a drag adds nodes and Ctrl + click selects (L2a's
  gesture); the panel says so. The foliage erase is Shift + drag (L2a's gesture).
- A colour-picture export is not offered: L1b built no command for it; the `.dti` export of the colours is.
- `level.view` adds `unfold` / `fold` (the Outliner's expanders were the only person action without an MCP way).
